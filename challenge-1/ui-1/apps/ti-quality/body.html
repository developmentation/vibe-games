About this program

Technology and Innovation (TI) defines the quality standards and engineering practices that all Government of Alberta development teams are expected to follow. This program brings together guidance on coding standards, testing, security, release management, and continuous improvement into one place.

Mandatory for all TI-managed projects

These standards apply to all software developed, maintained, or procured by Technology and Innovation, including projects delivered by vendor partners under GoA contract. Teams are expected to self-assess against these practices during sprint planning and project intake.

Practice areas

Choose a practice area below to read the full guidance and requirements.

Standards & code review

GoA coding standards, branching strategy, pull request templates, peer review checklists, and documentation requirements for all project repositories.

Best for: developers and technical leads setting up or onboarding to a project

Testing practices

Unit, integration, end-to-end, and accessibility testing requirements, coverage thresholds, test-driven development guidance, and approved testing frameworks.

Best for: developers and QA specialists designing or reviewing a test suite

DevSecOps & release management

CI/CD pipeline requirements, SAST and DAST security scanning, vulnerability management timelines, release gates, change management, and approved deployment strategies.

Best for: DevOps engineers, release managers, and application security teams

Continuous improvement

Sprint retrospective formats, quality metrics and targets, technical debt management, blameless post-mortems, and the TI capability maturity self-assessment.

Best for: delivery leads and team leads assessing and improving team health
